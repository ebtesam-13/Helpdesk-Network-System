# 🛠️ Enterprise Helpdesk Network System

تطبيق إدارة تذاكر الدعم الفني للشبكات المحلية (LAN) مصمم بلغة Python و Tkinter.

## 🌟 المميزات
- **تطبيقات منفصلة:** تطبيق للموظفين (`employee_app.py`) وتطبيق لقسم الـ IT (`it_admin_app.py`).
- **قاعدة بيانات مشتركة:** الربط عبر مسار شبكي موحد (`UNC Path`) باستخدام SQLite.
- **دعم ثنائي اللغة:** واجهة كاملة باللغتين العربية والإنجليزية (AR/EN).
- **تصدير تقارير:** تصدير التذاكر إلى ملفات Excel منسقة.

## 🚀 طريقة التشغيل
1. ضبط مسار المشاركة في الكود:
   ```python
DB_PATH = r"\\YOUR-SERVER-NAME\HelpdeskShare\tickets.db"
```
